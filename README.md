## ✨ نظرة عامة

**TROF System** هو بوت ديسكورد عربي متكامل، يأتي مع **لوحة تحكم ويب احترافية** للتحكم بكل شي بدون أوامر. 

صُمم خصيصاً للمجتمعات العربية، مع دعم كامل للغة العربية (RTL) والإنجليزية (LTR).

## 🎯 المميزات

### 📊 المستويات
- XP كتابي وصوتي
- رتب تلقائية لكل مستوى
- لوحة صدارة حية
- إحصائيات مفصلة

### 🎫 التكتات
- أنواع تكتات قابلة للتخصيص
- رتب دعم متعددة
- رسائل ترحيب مخصصة
- سجل كامل

### 🛡️ الحماية
- مكافحة السبام
- مكافحة الروابط
- مكافحة التخريب (Anti-Raid)
- حماية الحسابات الجديدة

### 🛒 المتجر
- خلفيات بروفايل
- شارات مميزة
- أحجام بروفايل
- شراء بالعملات

### 👋 الترحيب
- رسائل ترحيب مع صور مخصصة
- رسائل وداع
- رتب تلقائية
- تصميم كامل للبطاقة

### 🎨 Embed Builder
- صانع رسائل تفاعلي
- معاينة حية
- قوالب محفوظة
- إرسال مباشر

### ⚡ الاختصارات

- دعم كامل للأوامر

### 👑 VIP / Premium
